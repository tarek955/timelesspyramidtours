# Timeless Pyramids Tours - الموقع الرسمي

## 🏛️ نبذة عن الموقع
موقع تعريفي احترافي لشركة Timeless Pyramids Tours - متخصصة في تقديم رحلات سياحية فريدة وممتعة لاستكشاف عجائب الحضارة المصرية القديمة.

## 📋 المحتويات
- **الصفحة الرئيسية**: عرض تقديمي جذاب للشركة
- **من نحن**: معلومات عن الشركة والخدمات
- **الرحلات**: عرض الرحلات المتاحة بالتفاصيل والأسعار
- **المعرض**: مجموعة من الصور من الرحلات السابقة
- **التواصل**: نموذج اتصال وبيانات التواصل

## 🛠️ التكنولوجيا المستخدمة
- **HTML5**: هيكل الصفحات
- **CSS3**: التصميم والأنماط
- **JavaScript**: التفاعلية والحركة
- **Font Awesome**: الأيقونات
- **Responsive Design**: يعمل على جميع الأجهزة
